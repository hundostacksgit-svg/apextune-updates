Changelog

What changed.

The one command fetches the newest script every run, so every entry here reaches you the next time you run it, on the same key, for nothing.

v1.4.0 · September 2026

Numbers, a page, a hash

  • Before and after, measured: processes, threads, handles, memory in use, three seconds of idle CPU and DPC time. The after-restart task writes the same six numbers
  • The report is also a page: numbers up top, kept-and-why, warnings, the BIOS checklist readable on a phone next to the BIOS screen, per-game settings, everything done. It opens in the browser at the end; the app has an Open the report button
  • A game running when you press Run gets a warning and a question first
  • The command checks the script against the hash published next to it before running it, and fetches again on a mismatch; a stale hash fails the publish check, so the two cannot drift
  • App: the target on its own line, labels that fit, Enter in the key box runs, the footer counts the run's time
v1.3.0 · September 2026

The app

  • The one command now opens a window: the PC as it read it, the process count and target, the advice, a tick box for every phase and every startup app, the options, the key, a live log and progress, and buttons for undo, the free report, the folder and restart
  • It is the same one file: the window is drawn from XAML held in the script and the work runs in a second PowerShell instance, so nothing is installed and the window never freezes
  • The console flow stays: $env:OMNIDX_MODE='console'
  • New switches: -Skip for phases, -NoRestart, -Probe (the PC as JSON), -Screenshot (draws the window to a PNG without showing it)
  • The Windows check draws the window on every change and the picture on the site comes from it
v1.2.0 · September 2026

The debloat

  • Thirty more app patterns: the new Outlook, Teams, Copilot, Edge's in-game overlay, the widgets runtime, and the games, media players, antivirus and shopping trials PC makers add. Removed for every account and from the image
  • OneDrive uninstalled when nobody is signed in to it; kept, minus its auto-start, when you are. Undo reinstalls it
  • Legacy Windows removed when present: Internet Explorer 11, the 2009 Media Player, WordPad, Steps Recorder, Math Input Panel, XPS printing, Work Folders, the PowerShell 2.0 engine. Fax and Scan stays with a printer, Hello face with a Hello camera. Undo re-enables each
  • Edge's shopping assistant, recommendations, Spotlight, feedback prompts and usage reporting off by policy
  • Kept gone: consumer features, suggested apps, silent installs, account nags and the "finish setting up" screen off by policy
  • Cleanup: temp files older than a day, the Windows Update download cache and the peer-to-peer cache, with the space freed printed
  • The free report lists the legacy pieces it would remove on your PC
v1.1.0 · September 2026

Reads more, asks better, proves the number

  • Shows what starts with Windows and lets you pick what stays on, by number, before switching the rest off
  • Offers to close Discord and Spotify so they can be tuned in the same run
  • Finds games through Steam's library list, Epic's manifests and the Riot and Xbox folders instead of crawling Program Files
  • Checks your RAM speed against its rated speed and says outright when XMP / EXPO is off; warns on single-channel memory, an old GPU driver, a display set below its refresh rate, no page file, Windows on a hard disk, less than 16 GB, an old Windows 10 build, running on battery, another optimizer installed
  • Keeps the Xbox accessory service when a controller is connected; notes OEM extras and third-party antivirus without touching them
  • Prints a target process count for your PC, and writes the after-restart count to a file by a one-shot task that removes itself
  • Tunes the signed-in account when a standard user gave an administrator's password at the prompt
  • Free report mode now lists exactly what would be switched off and kept on your PC, and saves it
  • New cuts: Recall, lock-screen ads, Windows Error Reporting, Store app pre-launch, Sticky Keys popups, the ten-second startup delay, receive segment coalescing, the Widgets host, NVIDIA telemetry and its crash-report tasks, eight more telemetry tasks, per-game I/O and page priority
  • Refuses Windows Server and PowerShell 7 with a plain explanation; warns on a work domain, a pending restart, a virtual machine and low disk space
  • Report lists what was kept and why, the games it found, a summary file and full before-and-after process lists; a transcript of the run is saved
  • The command fetches past caches, hands PowerShell 7 over to Windows PowerShell itself, and takes options from one more line
  • Keys can move to a new PC by yourself, once every 30 days, from the key page (with the licence server)
v1.0.0 · September 2026

The first one

  • Reads the PC and decides the safe bar from what it finds
  • Startup apps, services, scheduled tasks, preinstalled apps, telemetry and background activity cut; system, network, Discord, Spotify and browsers tuned
  • The OmniDx power plan, sixteen game profiles, a BIOS checklist for the board, GPU control-panel notes
  • Restore point, a record of every change, undo in one file
  • Keys locked to the PC: TUNE for one, SQUAD for five
