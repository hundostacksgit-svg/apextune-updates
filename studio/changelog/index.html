Changelog

What changed.

The one command fetches the newest script every run, so every entry here reaches you the next time you run it, on the same key, for nothing.

v1.15.0 · September 2026

Why is the number up again

  • Status names the processes running now that were not running right after the tune: whatever was opened since, or a launcher that came back. Settings are checked separately; this is the answer to the question Task Manager raises
v1.14.0 · September 2026

One notification, when it matters

  • When the keep task finds a feature update has turned five or more settings back on, it puts them back and shows one Windows notification saying so; a stray value or two is fixed quietly
  • The transparency page lists the games it writes profiles for, with their executables, generated from the script
v1.13.0 · September 2026

Quiet about the key

  • The one command no longer puts the key on the command line of the administrator window it opens (Windows keeps command lines in logs and the run's transcript); it crosses in a file only your account can read, which is deleted on arrival
  • The keep task's log line now ends with the process count at that sign-in, so keep-log.txt doubles as a record of the number over time
  • The keep task leaves the Windows 11 right-click menu choice alone, like the other personal preferences
v1.12.0 · September 2026

Faster read

  • Reading the PC times each of its slow parts and keeps the numbers in the machine record, so a slow read can be seen rather than guessed at; the Windows check prints them
  • The controller check looks only in the device classes a controller can be in, and listing every display mode (which some drivers take ages over) gets ten seconds before it is left out
v1.11.0 · September 2026

Every process, in the report

  • The report page folds in the full process lists from before and after, name by name with counts and memory, and says whether the PC is kept cut
v1.10.0 · September 2026

No means no

  • Saying no to keeping it cut, or running with -NoKeep or -Skip keep, also removes the keep task an earlier run left, and says so
  • The Windows check's second run now passes no key at all and says no to the keep task: it must find the key the first run bound, be accepted, record nearly nothing, and take the task down
v1.9.0 · September 2026

The run, word for word

  • The run-it page shows the log of the last run on the build machine: every phase header, everything done, the numbers, exactly as the console printed them. Committed by the check itself, so it cannot be edited by hand
  • The free report mentions the keep task and status mode
v1.8.0 · September 2026

Read me first

  • Game profiles: the game folders are walked once and every game is a lookup, instead of one walk per game; the games phase is minutes faster on a full Program Files
  • The PC remembers its key: a second run asks for nothing, in the console and in the app, whose button now says Run it again. Undo in the app asks for a second click
  • C:\OmniDx gets a README.txt: what every file there is, how to undo, how to see status, and that nothing in the folder talks to the internet
  • The report, text and page, ends with the status command; the one command prints "Script verified" with the hash it matched, so you can see the check happen
  • Hibernation is read from the registry instead of powercfg's text, so a desktop running Windows in another language gets the same treatment
  • The transparency page lists what the keep task leaves alone, generated from the script
  • The Windows check now runs the tune a second time with the same key and requires it to be accepted and to find nearly nothing left to do, then undoes both runs; the proof line shows the second run's count
v1.7.1 · September 2026

Thirty-one games, and the disk

  • Fifteen more game profiles: The Finals, Dota 2, Battlefield 6, Deadlock, Delta Force, ARC Raiders, Helldivers 2, Warframe, Destiny 2, Halo Infinite, Dead by Daylight, Hunt: Showdown 1896, War Thunder, World of Warcraft and Squad; each with its competitive in-game settings in the report
  • NTFS is allowed more cache memory on PCs with 16 GB or more, and TRIM is switched on for SSDs when a cloned or old install left it off. Both recorded with the previous value; undo puts them back
  • The proof line on the front page now also shows how many settings the Windows check turned back on by hand and the keep task put back
  • The publish check now refuses a recorded change type with no undo handler, a window control the code names but the XAML lacks, and a bootstrapper flag the script does not declare
v1.6.0 · September 2026

Kept cut

  • Windows updates turn pieces of the tune back on. Say yes at the end of a run and a small task, three minutes after each sign-in, compares every recorded service, task and value with the machine and puts back what drifted. It never touches startup apps or your own settings, logs to C:\OmniDx\keep-log.txt, and undo removes it. -NoKeep never makes it
  • Status: $env:OMNIDX_MODE='status' says which runs are in place, what an update put back, when the keep task last ran, the after-restart count and the key. Changes nothing; the app has a button for it
  • Undo walks back every recorded run, newest first, so a PC tuned twice ends up as it was before the first run; each record then moves to done\ and a second undo says there is nothing left
  • C:\OmniDx keeps the last ten runs of logs, reports and snapshots; undo records and their backups stay until undo uses them
  • Restart now counts down ten seconds; any key stays
  • The Windows check now proves the keep task: it turns a service, a task and a policy value back on by hand, runs keep.ps1, and requires all three put back and status clean; then undo must remove the task and leave nothing behind
v1.5.0 · September 2026

Run before published

  • Every change now runs the whole tune with a real key on a fresh Windows build machine, then undoes it, before the site publishes; the numbers from that run are on the front page and the trust page
  • The report names the processes that were running before and are not now
v1.4.0 · September 2026

Numbers, a page, a hash

  • Before and after, measured: processes, threads, handles, memory in use, three seconds of idle CPU and DPC time. The after-restart task writes the same six numbers
  • The report is also a page: numbers up top, kept-and-why, warnings, the BIOS checklist readable on a phone next to the BIOS screen, per-game settings, everything done. It opens in the browser at the end; the app has an Open the report button
  • A game running when you press Run gets a warning and a question first
  • The command checks the script against the hash published next to it before running it, and fetches again on a mismatch; a stale hash fails the publish check, so the two cannot drift
  • App: the target on its own line, labels that fit, Enter in the key box runs, the footer counts the run's time
v1.3.0 · September 2026

The app

  • The one command now opens a window: the PC as it read it, the process count and target, the advice, a tick box for every phase and every startup app, the options, the key, a live log and progress, and buttons for undo, the free report, the folder and restart
  • It is the same one file: the window is drawn from XAML held in the script and the work runs in a second PowerShell instance, so nothing is installed and the window never freezes
  • The console flow stays: $env:OMNIDX_MODE='console'
  • New switches: -Skip for phases, -NoRestart, -Probe (the PC as JSON), -Screenshot (draws the window to a PNG without showing it)
  • The Windows check draws the window on every change and the picture on the site comes from it
v1.2.0 · September 2026

The debloat

  • Thirty more app patterns: the new Outlook, Teams, Copilot, Edge's in-game overlay, the widgets runtime, and the games, media players, antivirus and shopping trials PC makers add. Removed for every account and from the image
  • OneDrive uninstalled when nobody is signed in to it; kept, minus its auto-start, when you are. Undo reinstalls it
  • Legacy Windows removed when present: Internet Explorer 11, the 2009 Media Player, WordPad, Steps Recorder, Math Input Panel, XPS printing, Work Folders, the PowerShell 2.0 engine. Fax and Scan stays with a printer, Hello face with a Hello camera. Undo re-enables each
  • Edge's shopping assistant, recommendations, Spotlight, feedback prompts and usage reporting off by policy
  • Kept gone: consumer features, suggested apps, silent installs, account nags and the "finish setting up" screen off by policy
  • Cleanup: temp files older than a day, the Windows Update download cache and the peer-to-peer cache, with the space freed printed
  • The free report lists the legacy pieces it would remove on your PC
v1.1.0 · September 2026

Reads more, asks better, proves the number

  • Shows what starts with Windows and lets you pick what stays on, by number, before switching the rest off
  • Offers to close Discord and Spotify so they can be tuned in the same run
  • Finds games through Steam's library list, Epic's manifests and the Riot and Xbox folders instead of crawling Program Files
  • Checks your RAM speed against its rated speed and says outright when XMP / EXPO is off; warns on single-channel memory, an old GPU driver, a display set below its refresh rate, no page file, Windows on a hard disk, less than 16 GB, an old Windows 10 build, running on battery, another optimizer installed
  • Keeps the Xbox accessory service when a controller is connected; notes OEM extras and third-party antivirus without touching them
  • Prints a target process count for your PC, and writes the after-restart count to a file by a one-shot task that removes itself
  • Tunes the signed-in account when a standard user gave an administrator's password at the prompt
  • Free report mode now lists exactly what would be switched off and kept on your PC, and saves it
  • New cuts: Recall, lock-screen ads, Windows Error Reporting, Store app pre-launch, Sticky Keys popups, the ten-second startup delay, receive segment coalescing, the Widgets host, NVIDIA telemetry and its crash-report tasks, eight more telemetry tasks, per-game I/O and page priority
  • Refuses Windows Server and PowerShell 7 with a plain explanation; warns on a work domain, a pending restart, a virtual machine and low disk space
  • Report lists what was kept and why, the games it found, a summary file and full before-and-after process lists; a transcript of the run is saved
  • The command fetches past caches, hands PowerShell 7 over to Windows PowerShell itself, and takes options from one more line
  • Keys can move to a new PC by yourself, once every 30 days, from the key page (with the licence server)

  • Startup apps, services, scheduled tasks, preinstalled apps, telemetry and background activity cut; system, network, Discord, Spotify and browsers tuned
  • The OmniDx power plan, sixteen game profiles, a BIOS checklist for the board, GPU control-panel notes
  • Restore point, a record of every change, undo in one file
  • Keys locked to the PC: TUNE for one, SQUAD for five
