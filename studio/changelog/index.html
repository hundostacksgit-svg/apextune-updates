Changelog

What changed.

The one command fetches the newest script that passed the Windows check, every run, so every entry here reaches you the next time you run it, on the same key, for nothing.

v1.38.0 · September 2026

Quieter where a PC lacks a piece

  • A power-plan setting this PC's driver does not have is skipped and counted on one line, instead of powercfg's error appearing in red
  • Game Bar's presence writer is switched off only where Game Bar is installed; a registry key Windows will not let the tune create is named once, and the value left alone
  • A run that finds everything already done still writes its (empty) record, so undo and status always have a complete list of runs
  • "1 app removed", not "1 apps": the counts on screen agree with their nouns
v1.37.0 · September 2026

Said on screen, not only in the report

  • Anything another tool left switched off is said in the console while the PC is read, not only in the report, and the README in C:\OmniDx names the section
v1.36.0 · September 2026

What other tools left switched off

  • The report, the free report mode too, gains "Left by other tools": Defender switched off by policy, automatic updates off, the Windows Update service disabled, SmartScreen off, User Account Control off, the CPU security mitigations off. The tune changes none of them; it names each with the way back, so a hole another script made is not blamed on this one and not kept unknowingly
v1.35.0 · September 2026

Every start since the tune, on record

  • The keep task notes the boot time of each start on its log line, and status lists the starts since the tune, oldest first, next to the figure from before it: a record over weeks, in Windows' own numbers, not one screenshot
  • The after-restart task waits up to three minutes more for Windows to log that start's boot time, so the line has it far more often
  • The report's first next step says where the boot time will show up
v1.34.0 · September 2026

Boot time, before and after, in Windows' own figures

  • The report carries the boot time of the last full start before the tune, the after-restart line adds the first start after it, and status shows both side by side from then on. No stopwatch of ours: it is the figure Windows writes in its own boot-performance log a few minutes after the desktop appears
  • The key page sends the keys to your checkout address again with one press: the address on file and nowhere else, ten minutes apart, and the page says where they went
  • The owner page proves the mail before the first sale with one test email (Resend's exact refusal shows when the domain is not verified yet), sends every unsent order in one press, shows totals since the first sale above the recent orders, and emails the week's figures on demand and every Monday
  • Undo no longer waits five minutes on each optional piece of Windows when Windows Update is out of reach: after the first one times out it lists the rest for Settings > Apps > Optional features and gets on with it
v1.33.0 · September 2026

An old guide's clock, a stuck app at shutdown, and no guessing

  • A forced platform clock is removed: the "bcdedit /set useplatformclock true" line from a 2015 tweak thread makes every timer read cost more on a modern CPU and unsettles frame pacing. The tune deletes the value where it finds it, Windows picks the clock source again after a restart, and undo sets it back
  • Extreme: an app that will not close at shutdown is ended after its two seconds instead of holding the "this app is preventing shutdown" screen
  • The licence server shuts out guessing: twenty key-page tries, forty key checks or ten moves from one connection in ten minutes, and it answers "too many tries" until the window passes, while everyone else is served. Ten wrong owner tokens close the owner page the same way; the right token is never counted
  • The key tool makes and checks keys only. Nothing derives a buyer's key from an order any more: keys exist where the server minted them after Square confirmed the payment
v1.32.0 · September 2026

Drop Extreme, keep the tune

  • Undo the last run only: $env:OMNIDX_MODE='undolast' puts back the newest run (the Extreme one, say) and leaves the earlier runs and the keep task in place. Full undo still walks back every run. The keep task now goes only when no run is left recorded
  • The "after" count waits for the services that were told to stop to finish stopping, up to twenty seconds, so the number on screen is closer to the one after a restart
  • The Windows check undoes the Extreme run on its own first, checks that the two earlier runs are untouched and status is clean, then undoes the rest. A run put back alone now leaves the standard tune exactly as it was: the power plan, the TCP settings and the keep task no longer record themselves again on every run
  • Status and the key check ask the licence server, when one is configured, what it holds on the key: issued and on how many PCs, or switched off by a refund. Without a server they answer as before
  • The report opens with five next steps: restart, the BIOS items that matter on this PC, the GPU control panel, the launchers, and where status and undo are
  • The BIOS checklist and the GPU notes know a laptop: the memory profile, fans, power limits, the integrated graphics and the memory timings are written for what a laptop actually exposes, and the GPU switch (Hybrid, Discrete, MUX) and the per-game High performance setting take their place; Whisper Mode, Battery Boost and Radeon Chill are named as the frame caps they are
v1.31.0 · September 2026

Service hosts grouped, twenty-seven more tasks, Defender on a leash

  • Extreme now groups the service hosts the way Windows ran for twenty years: on a PC with more than 3.5 GB of RAM every service gets its own svchost.exe, which is most of the process count. A threshold above the installed RAM puts them back into shared hosts, twenty to forty processes fewer after a restart. The cost is that a crashing service takes its group down with it, which a restart fixes. Extreme also turns the System Guard broker off where it still ships, and shutdown waits two seconds for a slow service or app instead of five and twenty
  • The standard tune disables twenty-seven more scheduled tasks nobody on a gaming PC asked for: the compatibility appraisers, memory and disk-usage diagnostics, data-usage bookkeeping, the flighting reporters, SQM, offline files, storage tiers, remote assistance, print provisioning, media-library sharing, the indexer's maintenance, roaming profile uploads, the shared-PC cleanup, the Store's remote install and the end-of-support nag
  • Defender stays, and its scheduled scans are capped at a quarter of the CPU instead of half; real-time protection is untouched, and the cap is skipped when another antivirus is in charge. Undo puts the old figure back
  • Typing and inking history stays on the PC, handwriting errors are not reported, the compatibility inventory is off, the clipboard is not synced through the cloud, and nobody can offer to take the screen over through Remote Assistance. On 11, the account nags on Start go, and "End task" appears on the taskbar's right-click menu for the game that stops answering
  • Squad is now $39.99 for three keys, one PC each: yours and two to give away. The $69.99 five-PC key is gone. And the key goes to the email you gave at checkout the moment Square confirms the payment, as well as onto the page Square sends you to
  • Eighteen more game profiles, forty-nine in all: Battlefield 2042, EA Sports FC 26, NBA 2K26, Palworld, Path of Exile 2, Diablo IV, Monster Hunter Wilds, Elden Ring and Nightreign, Cyberpunk 2077, Baldur's Gate 3, Star Citizen, DayZ, Arma Reforger, Hell Let Loose, Genshin Impact, Ready or Not, Final Fantasy XIV, STALKER 2 and Sea of Thieves, each with its settings in the report; FiveM gets the GTA V profile. The power plan also turns throttle states off on a desktop and Wi-Fi power saving off (the cause of most Wi-Fi ping spikes); flow control goes off on the live adapter
  • The report gains a section on launchers, overlays and helper apps: the one or two settings that matter in Steam, Epic, Battle.net, the Riot client, the EA app, Ubisoft Connect, GOG Galaxy, Discord, the NVIDIA and AMD apps, the Xbox app, Overwolf, Wallpaper Engine and the RGB suites (iCUE, Synapse, G HUB, SteelSeries GG, Armoury Crate, MSI Center), for the ones found on your PC
  • The one command now fetches the exact copy of the script that passed the whole Windows check, published by the check next to its hash. A change that fails the check never reaches anyone. The check also runs when the test tooling changes, not only the script

Extreme, and thirty more services

  • The standard tune cuts thirty more services nobody on a gaming PC uses: peer networking, routing, SNMP, mixed reality, shared PC, SMS, troubleshooting, UE-V, Work Folders, Wi-Fi Direct, scanners, spot verifier, cellular time, enterprise apps, File History, data usage, and the Hyper-V guest services on a physical PC. Game Bar's presence writer, the one Game Bar process that runs anyway, is off
  • Extreme, a second command on the key page marked caution: eighteen more services (notifications, clipboard history, nearby sharing, Windows Search, superfetch on SSDs, capture, media controls, pairing brokers, voice activation, DVR broadcast), the shell drawn plain, exclusive fullscreen for every game, multi-plane overlay off, memory compression off with 16 GB or more, the dynamic tick off on desktops, the Xbox pieces gone unless they are in use, and nine advanced BIOS items in the report. It asks first; undo puts all of it back; the keep task leaves the shell choices alone. In the app it is a tick box; from the console, -Extreme
  • The Windows check now runs a third pass with Extreme on the build machine, requires it to record its extras and leave status clean, then undoes all three runs

Keys come from one place

  • The Windows check first proves a first run refuses with no server and changes nothing, then runs the tune against a stand-in server on the build machine itself
