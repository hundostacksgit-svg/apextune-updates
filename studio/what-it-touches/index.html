What the keep task checks

Only if you said yes to it. Three minutes after each sign-in it compares every service, scheduled task and registry value above with the machine and sets again what a Windows update turned back on. It never adds anything, and anything under these paths is left alone on purpose: if it changed after the tune, it was you, in Settings or Task Manager, and that wins.

  • \Control Panel\
  • \StartupApproved\
  • \CurrentVersion\Run
  • \Explorer\Advanced
  • \GameBar
  • GameConfigStore
  • \GameDVR
  • \Accessibility\
  • \UserGpuPreferences
  • \VisualEffects
  • \Explorer\Serialize
  • \Personalization
  • \Classes\CLSID\
  • \Themes\Personalize
  • \PushNotifications
  • \Notifications\
  • \CurrentVersion\Search
  • \WindowMetrics
  • \Dwm

Its log is C:\OmniDx\keep-log.txt; -NoKeep never makes it; undo removes it. Read the comparison itself: Get-Drift in the script.

And, outside the registry

  • A System Restore point, and a registry export of the areas above plus the service list, before anything else
  • A power plan named OmniDx, made from Ultimate Performance; undo makes your previous plan active again and deletes it
  • Hibernation off on desktops (hiberfil.sys freed); left alone on laptops
  • TCP settings by netsh and adapter properties by their driver names; every one recorded with its previous value
  • Discord's settings.json and Spotify's prefs, backed up first, only while the apps are closed
  • Store app pre-launch off (Disable-MMAgent); NTFS last-access stamps off; NTFS allowed more cache memory with 16 GB or more; TRIM switched on for SSDs if it was off. Each recorded with its previous value
  • One scheduled task that runs once at your next sign-in, writes the after-restart process count and removes itself; skip it with -NoAfterCount
  • One scheduled task, "OmniDx keep", if you say yes to it: three minutes after each sign-in it compares the services, tasks and values above with the machine and puts back what a Windows update turned on. It never touches startup apps or personal preferences, logs to C:\OmniDx\keep-log.txt, and undo removes it; -NoKeep never makes it
  • OneDrive uninstalled when nobody is signed in to it (files untouched; undo reinstalls); kept when you are
  • Edge policies: shopping assistant, recommendations, Spotlight, feedback prompts and reporting off; your tabs and settings untouched
  • Cleanup: temp files older than a day, the Windows Update download cache and the peer-to-peer update cache; not undoable, because none of it is anything
  • Memory integrity off only with -Aggressive, and only after asking again

Not touched, ever: Defender, the firewall, SmartScreen, UAC, Secure Boot, TPM, BitLocker, Windows Update, any anti-cheat, any driver, your files and browser data. The full list.
