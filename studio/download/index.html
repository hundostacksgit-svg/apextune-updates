Run it

One line. Nothing to download.

There is no installer, because there is nothing to install. Open PowerShell, paste this, press Enter. It asks for administrator rights itself and opens the app.

irm omnidx.net/go.ps1 | iex

Windows 10 (1903+) and Windows 11. Works in the PowerShell every one of them ships with; from PowerShell 7 it hands itself over to Windows PowerShell 5.1.

Watch it work 1:14
What opens

The app. Still one file, still nothing installed.

The command opens a window: your PC as it read it, the process count and the target for your machine, a tick box for every phase and every app that starts with Windows, the options, your key, and a live log while it runs. Undo, the free report, the folder and restart are buttons. It is the same script, drawn as a window; the console flow is still there for anyone who wants it.

This picture is drawn by the script itself on a build machine every time it changes, so it is never out of date. The machine in it is that build machine.

$env:OMNIDX_MODE='console'; irm omnidx.net/go.ps1 | iex

Prefer the console? This runs the same tune as a conversation in the PowerShell window instead.

What happens, screen by screen

Three to five minutes; the debloat is most of it. It talks the whole way through and asks before it changes anything.

  1. Close Discord and Spotify

    They are only tuned while they are closed, because both rewrite their own settings on exit. Everything else can stay open.

  2. Open PowerShell

    Press the Windows key, type powershell, press Enter. A plain window is fine — it asks Windows for administrator rights itself and opens a second window with them.

  3. Paste the command, press Enter

    It fetches the script from omnidx.net, runs it from memory and opens the app. If Windows asks "Do you want to allow this app to make changes?", that is the administrator prompt: yes.

  4. Read what it found

    The left of the window: your Windows build, CPU, GPU, RAM, board, whether it is a laptop, what it will keep, the number of processes running right now and the target for your PC. Anything worth knowing, like RAM running below its rated speed, is in yellow underneath.

  5. Tick what you want

    Every phase is a tick box, on by default. Every app that starts with Windows is listed; untick one to leave it on. The options that are off unless you say so, like cutting the Xbox services, are underneath.

  6. Paste your key and press Run

    From the page after you paid, the first time only: the PC remembers it, so every later run finds it filled in. The key is checked, then the run starts: a restore point, then each phase, with every change printed in the log as it happens. Discord and Spotify are closed so they can be tuned.

  7. Restart

    The report opens in your browser with the before and after (processes, threads, handles, memory, idle CPU), the warnings, the BIOS checklist for your board, the settings for each game it found, and a list of anything another tool left switched off (Defender, updates, SmartScreen, UAC, the CPU mitigations) with the way back. It is saved in C:\OmniDx, with a card next to it: the before and after on one picture, labelled as this PC's, for posting. Then press Restart; the services it told to stop are still unwinding until you do.

$env:OMNIDX_MODE='undo'; irm omnidx.net/go.ps1 | iex

        
Tried Extreme and want only that gone? This puts back the newest run and leaves the tune and the keep task in place:

        
$env:OMNIDX_MODE='undolast'; irm omnidx.net/go.ps1 | iex

        
Or, with no internet at all, in an administrator PowerShell:

        
powershell -ExecutionPolicy Bypass -File C:\OmniDx\undo\undo.ps1

      

      

        
Put it all back

        
Undo is one line, and it lives on your PC.

        

          Every change is written to C:\OmniDx\undo\changes-latest.json
          as it is made, with the value it had before. Undo replays that list backwards: services
          back to their start type, tasks back on, registry values restored, the power plan you
          had before made active again, Discord and Spotify's files put back from their backups.
        

        
Tuned twice? Undo walks back every recorded run, newest first, so the PC ends up as it was
          before the first one, and removes the keep task. No key is needed for undo. Neither is this site — the undo script is a plain file on your machine.
          And the System Restore point from before the run is still there if you would rather use that.

        
Want to know what is still in place, what an update put back, when the keep task last ran, what runs now that did not right after the tune, and what the licence server holds on your key (issued, on how many PCs, or switched off by a refund)? No charge, changes nothing, and it does not even need administrator rights:

        
$env:OMNIDX_MODE='status'; irm omnidx.net/go.ps1 | iex

        
Need help? $env:OMNIDX_MODE='support'; irm omnidx.net/go.ps1 | iex zips the run logs, the PC as it was read, the numbers and the change records to your desktop, keys masked, none of your files; attach it to your email.

      

    

  







  

    

      
Options

      
The defaults are right for almost everyone.

      
Each of these is off unless you ask. They ride on one more line before the command, so the command itself never changes.

    

    

      

        
🎮

        
Cut the Xbox services too

        
Kept by default when Game Pass or Minecraft is found, because they need them. If you use neither:

        
$env:OMNIDX_FLAGS='-CutXbox'; irm omnidx.net/go.ps1 | iex

      

      

        
🧷

        
Keep a startup app

        
Everything is disabled at startup unless you name it, by the name Task Manager shows:

        
$env:OMNIDX_KEEP='Wallpaper Engine,RTSS'; irm omnidx.net/go.ps1 | iex

      

      

        
⚠️

        
Aggressive: memory integrity off

        
VBS / HVCI costs a few percent of performance while it is on and is a real security feature. Off is a trade, so it is opt-in and asked about again before it happens.

        
$env:OMNIDX_FLAGS='-Aggressive'; irm omnidx.net/go.ps1 | iex

      

      

        
🔢

        
No after-restart count

        
By default one task runs once at your next sign-in, writes the process count and the boot time of that start to C:\OmniDx\after-restart.txt and removes itself. Skip it:

        
$env:OMNIDX_FLAGS='-NoAfterCount'; irm omnidx.net/go.ps1 | iex

      

      

        
⚡

        
Extreme — caution

        
Everything the tune does, then what the people who tune for a living set afterwards: every extra service, Game Bar entirely, animations and transparency off, the search box and notification toasts off, multi-plane overlay off, memory compression off, superfetch and Windows Search off, the dynamic tick off, the service hosts grouped the old way (twenty to forty processes fewer after a restart; a crashing service takes its group with it, which a restart fixes), the Xbox pieces gone unless you use them, and an advanced BIOS list. It asks first; undo puts all of it back. The command is on your key page after buying, or:

        
$env:OMNIDX_MODE='extreme'; irm omnidx.net/go.ps1 | iex

      

      

        
🔁

        
Not kept after updates

        
By default the tune asks to leave a small task that runs three minutes after sign-in and puts back what a Windows update turned on. It only touches what was recorded, never your own settings, and undo removes it. To never make it:

        
$env:OMNIDX_FLAGS='-NoKeep'; irm omnidx.net/go.ps1 | iex

      

      

        
🌐

        
DNS to 1.1.1.1

        
Your router's DNS is usually fine, so this is off. Flags can be combined with a space.

        
$env:OMNIDX_FLAGS='-Dns -CutXbox'; irm omnidx.net/go.ps1 | iex

      -CutXbox, -Keep, -Dns,

      -Yes — and is at omnidx.net/tune/omnidx.ps1 to read or save.

What is left on your PC

The report

        
C:\OmniDx\report-<date>.html, and the same as text. Opens in your browser at the end. Next to it: a card (card-<date>.png) with the before and after on one picture, labelled as this PC's, for posting (status mode writes one with the after-restart number); a full process list from before and after, a transcript of the run, a summary and the machine read as JSON, and after-restart.txt after your next sign-in.

      
↩️
The undo

        
C:\OmniDx\undo\: the record of changes and the script that replays them. Keep the folder; it is the way back.

      
🗂️
The backups

        
C:\OmniDx\backup\<date>\: Spotify's settings file, the service list and a registry export of the areas it touches, from before the run.
