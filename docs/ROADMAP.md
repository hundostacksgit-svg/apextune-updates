# Every way OmniDx Tune could be better, ranked

The research record behind the improvement rounds: what was looked at, what
the evidence says, what got built and what was rejected and why. Rounds are
worked top down; each one ships only after the Windows check, the browser
test and the Worker test pass. Numbers in this file come from the published
run record (`studio/assets/ci-run.json`) or from a named source.

## What was surveyed

- Every phase of `tune/omnidx.ps1` (3,100 lines): what it reads, cuts, sets,
  writes and undoes; the free report; the keep task; the report.
- The published run log and report of 1.49.0 (build machine: 149 → 138
  processes now, 386 changes, 3 warnings, 116 s; debloat 62 s of it).
- The site, the buy path, the key server, the docs, the support replies.
- Windows 11 24H2 / 25H2 changes: WMIC and PowerShell 2.0 removed (the
  script uses neither: CIM everywhere, and 5.1), the 36 inbox apps, Recall,
  Click to Do, the new Outlook and Teams (all already in the app list).
- The 2026 anti-cheat rules: FACEIT requires TPM 2.0 (Nov 2025), IOMMU and
  VBS (rolled out through 2026), Windows 11 (Oct 2026); Riot's Vanguard
  On-Demand (June 2026) requires Windows 11 25H2, Secure Boot, TPM 2.0,
  IOMMU, VBS and HVCI.
- What the other tools change (WinUtil, Win11Debloat, Winhance, Atlas), and
  what the tweak guides claim about HAGS, timer resolution, Game Mode, MPO,
  VBS, C-states and HPET, against what is measurable.
- AMD's dual-CCD X3D scheduling (the 3D V-Cache Performance Optimizer).

## Done outside the table

- **The owner's logo everywhere** (the eagle over OMNIDX): nav and footer
  on every page, favicons and app icons, the social card, banners and the
  profile picture; the card the script writes and the app window fetch the
  head from the site and fall back to the drawn mark offline (1.53.0,
  1.54.0).
- **The game-folder walk has a limit** (1.56.0): twenty-five seconds, then
  the run says how many folders wait for the next run; every listed game
  keeps its CPU profile by name regardless. Found by reading the published
  phase timings (games 7.7 s on a machine with no games at all).
- **The moving background**: one canvas behind every page, hard black,
  purple shades and small purple objects at different depths that drift,
  slide with the scroll and lean toward the pointer; still under reduced
  motion, paused in a hidden tab, lavender in the light theme.

## Looked at and left alone, with the reason

- **HAGS off on 8 GB cards.** The guides say it can stutter on small VRAM;
  DLSS frame generation requires it on, and on cards that do not support it
  the value is ignored. Left on; the report names it.
- **Timer resolution.** Windows 11 makes it per process; the tune already
  lets games ask for 0.5 ms (`GlobalTimerResolutionRequests`). A resident
  "timer tool" would be one more process, which is the opposite of the point.
- **C-states off, HPET off, "disable autotuning".** Not measurable at home,
  and two of them make things worse; the BIOS checklist says so in words.
- **VBS off by default.** Worth 5–15% in CPU-bound games and now a bannable
  state on FACEIT and VALORANT. Stays opt-in, and refused where those are
  installed (round 1).
- **Delivery Optimization disabled.** Breaks Store and Windows Update
  downloads on some builds; the tune sets it to manual (trigger-started).
- **Anything that lowers security** (Defender, Windows Update, Secure Boot,
  SmartScreen, UAC, CPU mitigations). Never; the report names other tools
  that did.
- **FPS numbers on the site.** The rule stands: nothing on screen that was
  not counted on the reader's PC.
