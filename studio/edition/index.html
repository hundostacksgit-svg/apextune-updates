The guide, step by step.

Two ways in. A clean install is the full experience and the one in the film. On your PC as it is, nothing is reinstalled and your files and apps stay. Both use the same one line.

Your key page (omnidx.net/studio/activate/) has this line with your key already in it, and the email with your key has it too. Below, TUNE-XXXX-XXXX-XXXX-XXXX stands for your key.

A clean install Recommended

About an hour, most of it the USB stick being made. You need a USB stick of 8 GB or more and a PC with internet.

  1. Back up what you want to keep

    A clean install erases the disk you install on. Copy your files to another drive or the cloud. Games re-download from their launchers; your saves in Steam Cloud, Epic and Battle.net come back by themselves.

  2. Make a Windows USB stick with Microsoft's Media Creation Tool

    Plug in the USB stick (everything on it is erased). Open microsoft.com/software-download/windows11, under Create Windows 11 Installation Media press Download Now, run it, accept, keep the language, pick USB flash drive and your stick. It takes 20 to 40 minutes. For a PC that cannot run Windows 11, use the Windows 10 page the same way.

  3. Put OmniDx Edition on the stick

    Keep the stick plugged in. Press the Windows key, type powershell, press Enter, and paste your line:

    $env:OMNIDX_KEY='TUNE-XXXX-XXXX-XXXX-XXXX'; irm omnidx.net/edition.ps1 | iex

    Type 1 and press Enter. It finds the stick and asks you to confirm it, asks a name for your Windows account (Enter keeps Player), downloads OmniDx Edition, checks it against the fingerprint published next to it, and writes it to the stick with your key. Nothing on this PC changes.

  4. Boot the PC from the stick

    Plug the stick into the PC you are installing on and restart it. As it starts, press the boot menu key and pick the USB stick. The screen usually says which key; if not:

    ASUS: F8
    MSI: F11
    Gigabyte, Dell, Lenovo, Acer: F12
    HP: Esc, then F9
    ASRock: F11
    Nothing works? Enter the BIOS (Del or F2) and put the USB stick first in the boot order
  5. Pick the disk

    Windows setup asks where to install. Pick the disk yourself: for a truly clean start, delete that disk's partitions and choose the empty space. Everything else answers itself: no account screens, no privacy questions. If it asks for a product key, choose I don't have a product key; a PC that had Windows 10 or 11 activates by itself.

  6. Watch it set itself up

    Windows signs in to your account once and a window shows OmniDx Edition setting itself up: about three minutes, then the tune in Extreme with your key. It restarts by itself (once more if Windows Update was waiting). Leave it be until the OmniDx Edition welcome appears.

  7. Drivers and games

    Install your graphics driver from NVIDIA, AMD or Intel, then your launchers. The account has no password to start with: add one in Settings > Accounts > Sign-in options. Game Boost starts by itself the first time a game fills the screen.

  3. Let it finish

Using it.

Everything is on the taskbar, on the left: OmniDx Search, OmniDx Browser, File Explorer, OmniDx Hub, Terminal.

Windows + S: find anything

Type an app or a game, a setting in plain words ("sound", "night light", "mouse speed"), a file, a sum like 12*7+3, a web address, or an action: boost, free up memory, restart, flush dns, turn printing on. Start a line with > to run a command.

Game Boost

Starts by itself when a game fills the screen and stops 20 seconds after it closes. Discord and Spotify keep playing: only their windows' extra processes go into Efficiency mode, and whatever you switch to comes straight back. Turn it on or off by hand in OmniDx Hub, or type boost in OmniDx Search.

Presets

OmniDx Hub > Presets. Balanced is Windows' own scheduling. Competitive, the default, puts the game first. Insane adds the OmniDx Insane power plan and the last of the latency settings, for a desktop on mains power. Restore Windows defaults puts all of it back.

OmniDx Browser

Ctrl+T new tab, Ctrl+W close, Ctrl+L address bar, Ctrl+Shift+T bring a tab back, Ctrl+1 to 9 jump to a tab, F11 full screen. Last session's tabs come back asleep.

Take it off.

OmniDx Hub > About > Remove OmniDx Edition, or the same line with option 3 (it only shows when the Edition is on the PC), or straight to it:

$env:OMNIDX_EDITION='undo'; irm omnidx.net/edition.ps1 | iex

Every value the Edition changed goes back and its apps and tasks go; restart afterwards to see the taskbar and sign-in screen as they were. The tune's own changes stay until its undo is run:

$env:OMNIDX_MODE='undo'; irm omnidx.net/go.ps1 | iex

Questions.

Is this a modified Windows, a custom ISO?

No. Windows installs from the USB stick Microsoft's own tool makes, unmodified and signed by Microsoft. The Edition adds an answer file (the file Windows setup reads so it can skip its questions) and a folder to the stick, then sets itself up on top of Windows the way you could by hand. Nothing of Windows is copied, changed or handed out, which is also why it keeps every Windows update. What custom builds cut instead.

Does it come with my key? What does it cost?

It comes with every key, at no extra charge: $19.99 for one PC, $39.99 for three keys (each friend gets the Edition too). Paid once, never renews; all sales are final.

Do I need a Windows licence?

Your own, as with any Windows install. A PC that had Windows 10 or 11 activated has a digital licence tied to its board and activates by itself after a clean install. A new build needs a licence from Microsoft or a retailer.

Does my key still work after a clean install?

Yes. The key is tied to the PC's board and CPU, not to the Windows install, so reinstalling Windows on the same PC is free and expected.

VALORANT, FACEIT, Fortnite: does anti-cheat work?

Yes. Defender, Windows Update, SmartScreen, Secure Boot, TPM and memory integrity stay exactly as Windows ships them, which is what Vanguard and FACEIT now require.

Windows 10 or 11? Home or Pro?

Both, and both. The film is Windows 11. On Home, Windows may ask once in Settings before OmniDx Browser opens web links; Edge and Chrome keep working either way.

Will it wipe my PC?

The clean install erases the disk you pick in Windows setup, and only that one; setup never picks a disk for you. "On your PC as it is" keeps everything.

How many frames will I gain?

No honest number fits every PC: it depends on your GPU, CPU and game. What the Edition does is take away what competes with the game (fewer processes, apps in the background kept light while you play, the timer and power plan held while a game runs), which shows most in steadier frame times and fewer drops. The tune's free report shows what it would change on your PC first.

Something went wrong during setup.

Setup keeps a log in C:\ProgramData\OmniDx\Edition\setup-log.txt. Run the line again: setup can run more than once, and it keeps the first record of every value, so the undo still puts back what was there before. To go back, use the undo above.
