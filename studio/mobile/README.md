# OmniDx Studio for iOS and Android

Capacitor wraps the same editor. See
[`docs/STUDIO-BUILD.md`](../../docs/STUDIO-BUILD.md) for store submission,
signing and the App Store purchase rule that decides how the iOS build behaves.

```bash
npm install
npm run sync           # build www/ and sync the native projects
npm run add:android    # once
npm run open:android   # Android Studio
npm run add:ios        # once, on a Mac
npm run open:ios       # Xcode
```

`www/` is generated by `copy-web.mjs` and is gitignored. Never edit it — change
`studio/app` and run `npm run sync` again.

**Before you try to install it:** the web version already installs to the home
screen on both platforms, with an icon and offline support, and takes about
fifteen seconds. Build the store versions for reach, not because the web one is
missing something.
