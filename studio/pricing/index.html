Questions people actually ask

Will it get me more FPS?

Usually some, and more consistent frame times almost always — fewer processes means fewer interruptions, and the power plan stops the CPU dropping its clock between frames. How much depends on your GPU and the game: if your graphics card is the bottleneck, no Windows tweak changes that. The BIOS checklist is where the big free gain is on most PCs: RAM running at its rated speed instead of the default.

Is it safe with anti-cheat? VALORANT, Fortnite, CS2?

Yes. Vanguard, Easy Anti-Cheat, BattlEye and Ricochet are never stopped, disabled or delayed, and nothing here injects into a game or touches game files. VALORANT (Vanguard On-Demand) and FACEIT now require Secure Boot, TPM 2.0, IOMMU and memory integrity on; the script reports all four, refuses to switch memory integrity off on a PC where either is installed, and the BIOS checklist says where each one is.

Does it lower my security to get the number down?

No. Defender, the firewall, UAC, SmartScreen, Secure Boot and Windows Update are not touched. The one trade that exists — memory integrity (VBS) off, which costs a few percent of performance while it is on — is opt-in with -Aggressive, explained, and asked about again before it happens. The report goes the other way too: if another tool ever switched Defender, updates, SmartScreen, UAC or the CPU mitigations off on your PC, it says so, with the way back.

Will it work on my laptop?

Yes, and it knows it is a laptop. The battery side of the power plan stays sensible, lid, brightness and sensor services stay, Wi-Fi and Bluetooth stay if you have them, and hibernation is left alone. Everything else is the same cut.

What if something breaks?

Run undo: $env:OMNIDX_MODE='undo'; irm omnidx.net/go.ps1 | iex, or double-click C:\OmniDx\undo\undo.ps1. Every change is put back from the record it kept. And there is the restore point from before the run, which puts the whole system back. A service you decide you wanted can be started again from Services in the usual way; the script sets things to manual, it never deletes them.

Will the bloat come back after an update?

Monthly updates, no: the apps are removed from the image as well as your account, and the policies that let Windows quietly install "suggested" apps are off. A feature update (the once-a-year kind) can re-provision a few Microsoft apps such as Outlook, Teams and Copilot. Run the command again after one; same key, same PC, free, and it takes the same three minutes.

Windows Update put a startup app back. Now what?

Run the command again. The PC remembers its key, so a second run asks for nothing; the same PC can run the tune as often as it likes, because the key is locked to the machine, not to a number of runs. If you said yes to the keep task, most of it has already been put back before you get there.

I got a new PC. Can I move the key?

Yes, by yourself: on the key page, "New PC? Move this key" moves it once every 30 days with your order or receipt number. Sooner than that, email support with your receipt. A key is one PC; that is what makes it cheap and what stops it being passed around. A new board, or a fresh Windows install on the same board, counts as the same PC if the board and CPU are the same.

Does it change my in-game settings?

For Fortnite, Apex Legends, Counter-Strike 2, Marvel Rivals, Rocket League, Rainbow Six Siege and Minecraft, it writes V-Sync off, motion blur off and the shadow and post-processing settings players use into the game's own settings file, after asking. It backs up each file first, skips a game that is running, and only changes a setting the file already has. Undo puts each value back. Everything else in the game is untouched, and the free report lists what it would write before you pay.

I stream. Will it break OBS?

No. With OBS Studio, Streamlabs Desktop or XSplit installed, the camera frame server and Windows Graphics Capture are kept, even in Extreme, and the report lists the encoder and capture settings worth checking. If your streaming app is somewhere else, add -Streamer to the command.

Does it overclock or undervolt?

Neither. Voltage belongs to your GPU's tool and your BIOS, and the tune never touches it. The report and the undervolt guide say how to undervolt safely (cooler and quieter for the same frames) and set a frame cap that stays smooth.

Should I use a custom Windows build instead?

Those builds reach their numbers partly by removing Defender, Windows Update and the protections anti-cheat now requires. The tune stops short of all of that, on genuine Windows, with an undo. For a clean start, the free answer file sets up a fresh install in one go. The full comparison.

What is after-restart.txt?

The number that counts is the process count after a restart, and nobody is at the keyboard to read it then. So the tune leaves one scheduled task that runs once at your next sign-in, waits two minutes, writes the count to C:\OmniDx\after-restart.txt and deletes itself. The same line carries the boot time of that start in Windows' own figure, next to the one the report took before the tune. It is the only thing the tune ever schedules, it is in the undo list, and -NoAfterCount skips it.

What is the keep task?

A feature update resets a few service start types, re-enables some scheduled tasks and puts a handful of values back. At the end of a run the tune asks whether to leave one small task, "OmniDx keep", that runs three minutes after each sign-in, compares what it recorded with the machine and sets again whatever drifted. It never touches startup apps or your own settings, writes one line per sign-in to C:\OmniDx\keep-log.txt with that start's boot time on it, and undo removes it. Say no, or pass -NoKeep, and it is never made. $env:OMNIDX_MODE='status' shows what it has found.

A work laptop? A virtual machine? A shared family PC?

A PC joined to a work or school domain gets a warning and a question first: group policy can put settings back, and IT may have opinions. A virtual machine runs but the numbers mean little there. On a family PC where a standard account gave an administrator's password at the prompt, the tune notices and applies the per-user settings to the account that is signed in, not the administrator's.
