Custom Windows builds, and where the tune stops.

A custom build is Windows with parts removed from the install image, or a script run over a fresh install that turns the protections off. The process counts look great. Here is what gets them there, what it costs, and the line the tune will not cross.

What it costs.

Anti-cheat

Since 2026, VALORANT's Vanguard and FACEIT require Secure Boot, TPM 2.0, IOMMU and memory integrity. A build that turned them off is a build those games will not start on.

Security

No Defender and no updates means the next browser exploit is yours to keep. The frames it bought are a few percent; the risk is the whole PC.

Trust

A modified image is software from a stranger with the keys to everything. You cannot check what else was changed.

Repairs

Official repair tools and feature updates expect the parts that were cut. When something breaks, the answer is usually a reinstall.
