Nothing to buy on this page

Windows 11 for games, by hand.

Everything the tune does is a setting you can reach yourself. This is the list, in the order that pays: what to change, where it is, and what each one costs you. Do all of it and you do not need the tune. Most people do the first three sections and stop, which is fine too.

Look first. Twenty seconds, four numbers.

Before changing anything, find out whether your PC has the common problems. Each of these is a number Windows already shows you.

🔢

How many things Windows is running

Press Ctrl+Shift+Esc, open Performance, click CPU. Bottom left, next to Threads and Handles, is Processes. Close your game and browser first and read it. A fresh Windows 11 sits around 150 with nothing open; every one of them takes turns on the CPU your game wants.

🧠

Whether your RAM runs at the speed you paid for

Same window, Memory. The Speed line says what the RAM is running at. If you bought 3200, 3600 or 6000 and it says 2133, 2400 or 4800, the memory profile is off in the BIOS. This is the single biggest free gain on most PCs, and section two fixes it. Also read Slots used: one stick of two is single channel, and a matching second stick is the best upgrade that PC can get.

🖥️

Whether the monitor is at its refresh rate

Settings › System › Display › Advanced display. If the monitor can do 144, 165 or 240 Hz and the box says 60, pick the higher one. Nothing else on this page is worth as much as this when it is wrong.

📋

Or let the free report read all of it

One line, no key, changes nothing: it reads the machine, counts the processes, checks the RAM speed, the refresh rate, the stick count, the GPU driver age, the page file, the drive, and what another tool may have left switched off, then stops.

$env:OMNIDX_MODE='report'; irm omnidx.net/go.ps1 | iex

The BIOS. Ten minutes, and where the real gains are.

Restart and press Del (most desktop boards) or F2 (most laptops, ASRock, Acer, Dell) while the logo shows. HP is F10. Nothing on the PC can do these for you, and anything that claims to should frighten you.

1️⃣

The memory profile: XMP, EXPO or DOCP

Under the overclocking or "Ai Tweaker" page, set the memory profile to the one your RAM is sold at. This is what turns 2133 into 3200. If the PC will not boot afterwards, it clears itself after two or three tries, and a slower profile still beats none.

2️⃣

Resizable BAR

Above 4G Decoding = Enabled, then Re-Size BAR Support = Auto. It needs CSM off (Boot page), which is fine when Windows is installed in UEFI mode, which it is on almost every PC sold since 2018. Worth a measurable gain on RTX 30, 40 and 50 cards and RX 6000 and later.

3️⃣

Secure Boot, TPM and IOMMU: on

VALORANT's Vanguard and FACEIT require Secure Boot, TPM 2.0, IOMMU (Intel VT-d or AMD-Vi) and Windows memory integrity on. Secure Boot is on the Boot or Security page; TPM is fTPM (AMD) or PTT (Intel) under Security or Trusted Computing; IOMMU is under CPU Configuration, or AMD CBS › NBIO on AMD boards. Leave all of them on even if you do not play those today.

4️⃣

And leave the rest alone

C-states, HPET, Spread Spectrum, PCIe link speed: the guides that tell you to change these are from another decade. Fast Boot on and the full-screen logo off saves a second per boot. Do not flash a new BIOS unless its notes name a fix for a problem you actually have.

Windows, in Settings. Half an hour.

Every one of these is a switch in a menu. None of them lowers security.

🎮

Gaming

Settings › Gaming › Game Mode: on. Captures: "Record what happened" off, so nothing records behind your game. Xbox Game Bar: "Open Game Bar using this button" off. On a Ryzen 7950X3D or 9950X3D leave Game Mode on whatever else you do: AMD's driver uses it to put games on the right half of the CPU.

⚡

The power plan

Balanced parks CPU cores and lets the PCIe bus and USB ports doze between frames. Make the Ultimate Performance plan visible and switch to it:

powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61

Then Control Panel › Power Options › pick it. On a laptop, use it on mains only.

🖱️

The mouse and the keyboard

Settings › Bluetooth & devices › Mouse › Additional mouse settings › Pointer Options: "Enhance pointer precision" off. That is mouse acceleration, and it is the first thing every competitive player changes. Accessibility › Keyboard: the Sticky Keys and Filter Keys shortcuts off, so five taps of Shift in a fight opens nothing.

🎨

Graphics

Settings › System › Display › Graphics › Default settings: Hardware-accelerated GPU scheduling on, Optimizations for windowed games on, Variable refresh rate on. Then add each game and set it to High performance, so a laptop never runs it on the integrated chip. For the lowest input latency, right-click a game's exe › Properties › Compatibility › "Disable fullscreen optimizations".

🚀

Startup, and what runs behind you

Task Manager › Startup apps: everything off except what you want at sign-in. Settings › Apps › Installed apps: uninstall the preinstalled ones you have never opened. Privacy & security › General: the advertising id and suggestions off. Diagnostics & feedback: required data only, tailored experiences off. Personalization › Start: recommendations and tips off.

🪟

Visual effects and updates

Search "Adjust the appearance and performance of Windows": Custom, then untick the animations and transparency, keep smooth fonts and thumbnails. Windows Update › Advanced options › Delivery Optimization: allow downloads from "devices on my local network" only, so your upload is not feeding other people's updates mid-match. Set Active hours to when you play, so a restart never lands then. Leave Windows Update itself on; it is not a tweak, it is patches.

Services and scheduled tasks. The fiddly hour.

This is where the process count comes from, and where a forum list goes wrong: it does not know whether you have a printer. Read each one against your own PC.

⚙️

Services, in services.msc

Double-click, set Startup type to Manual (starts only when something asks) or Disabled, and Stop it. Safe on nearly every PC: Fax, Phone Service, Downloaded Maps Manager, Retail Demo Service, Parental Controls, Remote Registry, Windows Error Reporting, Program Compatibility Assistant, Diagnostic Policy Service (manual), Windows Insider Service, Geolocation, Windows Media Player Network Sharing, Distributed Link Tracking, WalletService, Work Folders, SNMP Trap, Smart Card (unless you use one). Print Spooler only without a printer. Bluetooth Support only with no paired device. Windows Search only if you never search the Start menu. Never touch anything with "Windows Defender", "Windows Update", "Cryptographic", "RPC" or "Plug and Play" in its name, and never any anti-cheat.

🗓️

Tasks, in Task Scheduler

Task Scheduler Library › Microsoft › Windows. Right-click › Disable on: Application Experience (the compatibility appraiser), Customer Experience Improvement Program (all), DiskDiagnostic, Feedback (Siuf), Maps, Speech, Windows Error Reporting, Autochk Proxy, Family Safety, Device Information, and the Clip and CloudExperienceHost ones. Two dozen in all; each one is a click, and each one is something that wakes up and phones home while you play.

The apps you keep, told to behave.

Overlays are the usual cause of a stutter that "came from nowhere". None of these changes how an app looks or sounds; only what it does when you are not looking at it.

💬

Discord, Spotify, the browser

Discord: Settings › Windows Settings › "Open Discord" off; Advanced › Hardware Acceleration on; Game Overlay off unless you use it. Spotify: Settings › "Open Spotify automatically" off, hardware acceleration on. Chrome, Edge, Brave: System › "Continue running background apps when closed" off, "Use graphics acceleration" on; Edge also "Startup boost" off.

🕹️

Launchers and their overlays

Steam: Settings › In Game › overlay off unless you use it; Downloads › "Allow background processing of Vulkan shaders" off. Epic: "Run when my computer starts" off. Battle.net, EA app, Ubisoft Connect, GOG: launch at startup off, overlay off. NVIDIA app and AMD Software: the in-game overlay off unless you record. Xbox app: auto-start off.

🌈

The RGB and peripheral suites

iCUE, Razer Synapse, Logitech G HUB, SteelSeries GG, Armoury Crate, MSI Center: each runs four to twelve processes and polls your devices all day. Save your lighting and macros to the device's onboard memory, then set the suite not to start with Windows. Open it when you want to change something.

📺

The GPU control panel

NVIDIA Control Panel › Manage 3D settings: Low Latency Mode Ultra, Power management Prefer maximum performance, Vertical sync off, Texture filtering quality High performance. AMD Software › Gaming › Graphics: Radeon Anti-Lag on, Radeon Boost off, Radeon Chill off, Wait for vertical refresh off. Turn Reflex or Anti-Lag 2 on inside each game that offers it.

What not to do. The myths, and the ones that cost you a game.

Every one of these is in a popular guide or a paid "optimizer". None of them is worth it, and the last three are dangerous.

🚫

"Disable TCP autotuning"

It halves your download speed and does nothing for your ping. The setting that helps a game is Nagle off on the adapter you use (a registry value per adapter: TcpAckFrequency 1, TCPNoDelay 1), which makes a small packet leave now instead of after a wait.

🚫

"Disable HPET", "disable C-states", "timer resolution tools"

The HPET tweak is from 2013 and hurts frame pacing on modern CPUs. C-states off buys nothing you can measure at home and raises idle heat. A resident timer tool is one more process; Windows 11 already lets a game ask for the timer it wants.

⛔

Defender, Windows Update, SmartScreen, UAC, the CPU mitigations

Off, these are not "free frames". They are the reason a downloaded "FPS booster" can do what it likes to your PC. If a tool switched any of them off, switch them back on; the tune's report names them if it finds them that way.

⛔

Memory integrity off, if you play VALORANT or on FACEIT

Core isolation's memory integrity costs a few percent in CPU-bound games, and since 2026 Vanguard On-Demand and FACEIT require it on, with IOMMU. Turn it off and those games stop launching. For everything else it is your call, and Windows Security › Core isolation is the switch.
